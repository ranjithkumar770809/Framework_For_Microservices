2-Microservice Architecture Overview

This application implements the Database-per-Service pattern with synchronous HTTP REST communication between services.

+---------------------------------------------------------------------------------+
|                        ShopEase Frontend (Browser / SPA)                        |
+----------------------------------------+----------------------------------------+
                                         |
                       +-----------------+-----------------+
                       |                                   |
         REST API (Port 8081)                 REST API (Port 8082)
                       |                                   |
                       v                                   v
            +--------------------+               +--------------------+
            |   Product Service  |               |   Order Service    |
            |   (Spring Boot)    |<==============|   (Spring Boot)    |
            +---------+----------+  REST Client  +---------+----------+
                      |       (Stock Check & Deduction)    |
                      v                                    v
            +--------------------+               +--------------------+
            | MySQL: product_db  |               |  MySQL: order_db   |
            +--------------------+               +--------------------+
Port 8081

Product Service

  • Database: product_db (MySQL)
  • Role: Catalog CRUD, stock checking, inventory deduction/restoration.
  • Key Endpoints:
    • GET /api/products
    • POST /api/products
    • PUT /api/products/{id}/decrement-stock
    • PUT /api/products/{id}/restore-stock
Port 8082

Order Service

  • Database: order_db (MySQL)
  • Role: Order calculation, placement, cancellation, inter-service orchestration.
  • Key Endpoints:
    • POST /api/orders (calls Product Service)
    • GET /api/orders
    • PUT /api/orders/{id}/status
    • DELETE /api/orders/{id} (auto restocks)
